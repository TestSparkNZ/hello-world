┌──────────────────────────────────────────────────────────────────────┐
│ TECHNICAL IMPLEMENTATION                                             │
└──────────────────────────────────────────────────────────────────────┘

ARCHITECTURE:
• Modular design with separate concerns
• AmberClient: API communication and pricing logic
• GoodWeController: Inverter control framework
• SmartInverterController: Integration layer

DECISION ALGORITHM:
1. Fetch current prices from Amber API
2. Analyze import price, export price, and descriptors
3. Apply configurable thresholds
4. Make decision: CHARGE / DISCHARGE / NORMAL
5. Command inverter to appropriate mode
6. Log decision and outcome
7. Wait for next interval (default: 5 minutes)

SAFETY FEATURES:
• Battery SOC limits (min/max)
• Auto-return to normal on errors
• Graceful shutdown on Ctrl+C
• Credential protection
• Rate limit awareness

│ USAGE INSTRUCTIONS                                                   │
└──────────────────────────────────────────────────────────────────────┘

GET STARTED:
1. Read QUICKSTART.md
2. Get Amber API token: https://app.amber.com.au/settings/
3. Run: bash setup.sh
4. Run: python3 test_amber_api.py
5. Run: python3 amber_guide.py (learn about system)
6. Edit config.yaml with your credentials
7. Run: python3 smart_controller.py --once (test)
8. Implement GoodWe control for your model
9. Test thoroughly
10. Run: python3 smart_controller.py (production)
